# test_pr_gh_dash

Учебный репозиторий для тестирования gh-dash и сценариев работы с pull request.

## Цели
- проверка отображения open/closed/merged PR
- проверка diff, commits, activity
- проверка draft PR
- проверка фильтрации в gh-dash

## Usage

This repository is intended for practicing pull request workflows in gh-dash.
